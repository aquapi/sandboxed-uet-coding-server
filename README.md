# Server

Local server.

## `uv`

```sh
uv sync
uv run server.py
```

## `pip`

```sh
pip install fastapi uvicorn pyeryx
python server.py
```

# Client

Test client.

```sh
python client.py
```

Change test code in [./client/code.py](./client/code.py) or input in [./client/input.txt](./client/input.txt).
